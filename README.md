## Project Overview

Student performance can be influenced by multiple academic and personal factors. This project analyzes student performance data to uncover patterns in academic outcomes and understand how performance varies across different student groups and subjects.

The analysis transforms raw student data into meaningful insights using data cleaning, transformation, DAX, and interactive Power BI visualizations. The goal is to identify performance patterns and provide a clear analytical view of student outcomes.

The project focuses on moving beyond individual scores to understand broader trends that can support better academic decision-making.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization
- Dashboard Design

## Objectives

- Analyze overall student performance
- Identify subject-level performance patterns
- Compare performance across different student groups
- Explore factors associated with academic outcomes
- Identify high- and low-performing areas
- Present findings through an interactive dashboard
